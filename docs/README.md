# OctoAcme Project Management Docs

Use this page as the entry point to OctoAcme's project management process and guidance.

## Process flow

OctoAcme manages projects in five connected stages:

1. **Initiation:** Validate the need and desired outcome, identify stakeholders, and agree on success criteria and a high-level timeline.
2. **Planning:** Turn approved work into a prioritized backlog, define acceptance criteria and responsibilities, and align milestones, dependencies, and risks.
3. **Execution:** Build, test, review, and deliver work in increments while tracking progress and communicating blockers and risks.
4. **Release:** Deploy completed work, verify it in production, and communicate the release to stakeholders.
5. **Retrospective and continuous improvement:** After a sprint, release, or milestone, capture learnings and turn the most important improvements into owned, trackable actions.
